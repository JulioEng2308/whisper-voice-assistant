# Voice Assistant with Whisper and gTTS

An educational project based on the DIO lab
“Conversando por Voz Com o ChatGPT Utilizando Whisper (OpenAI) e Python”.

## Features

- Record audio using the microphone in Google Colab.
- Transcribe speech using Whisper.
- Convert a predefined response into speech using gTTS.
- Play the generated audio directly in the notebook.

## Technologies

- Python
- JavaScript
- Google Colab
- OpenAI Whisper
- gTTS

## How to Run

1. Open the notebook in Google Colab.
2. Run the cells in order.
3. Allow microphone access when prompted.
4. Record a short sentence.
5. Check the transcription and play the spoken response.

An internet connection is required.

## Current Status

This version uses a predefined response to demonstrate the audio workflow
without making paid OpenAI API requests.

ChatGPT integration is pending because API credits are required.
The assistant does not yet generate automatic answers to spoken questions.
